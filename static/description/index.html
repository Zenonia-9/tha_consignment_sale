Consignment Sale

A complete Odoo 19 consignment workflow covering orders, stock transfers, partial deliveries, backorders, settlements, customer invoices, commission bills, returns, and printable PDF reports.

Odoo 19 Inventory Accounting QWeb Reports Backorder Workflow

Main Features

Consignment Orders

Create and confirm consignment orders that automatically generate stock issue transfers to the shop.

Backorder Tracking

Backorder-aware transfer tracking using linked consignment pickings — partial deliveries handled seamlessly.

Settlement Workflow

Settlement records for sold consignment stock with automatic stock-out, invoice, and commission bill creation.

PDF Reports

A4/A5 QWeb PDF reports with a print wizard — professional consignment order documents ready to send.

Commission Bills

Automatic vendor commission bill creation on settlement confirmation, linked to the commission product template.

Returns

Return workflow for unsold consignment stock, linked back to the original consignment order.

Configuration Steps

1

Set up the consignment shop partner

Enable the consignment shop flag on the partner record and configure the consignment location, pricelist, and commission percentage.

2

Configure the consignment warehouse

Set the source and destination warehouse for consignment stock movements.

3

Create and confirm a consignment order

Confirm the order to automatically generate the issue transfer to the shop.

4

Validate transfers (with backorder support)

Validate full or partial transfers. Backorders remain linked to the consignment order via the transfer smart button.

5

Create a settlement

Record sold items, confirm the settlement to create stock-out, then generate the customer invoice and commission vendor bill.

6

Process returns (optional)

Use the return workflow to send unsold stock back to the source warehouse.
